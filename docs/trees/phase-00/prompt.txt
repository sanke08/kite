Draw a hand-drawn whiteboard-style architecture diagram, in the visual style of
Excalidraw or eraser.io.

STYLE — follow exactly:
- Background: solid very dark charcoal, near-black (#121212 to #1a1a1a).
  Completely flat. No gradient, no vignette, no texture, no grid, no dot grid.
- Every stroke, box outline, arrow and letter: chalk white / off-white
  (#f0f0f0). Hand-drawn look — slightly wobbly lines, imperfect rectangle
  corners, as if sketched with a marker on a blackboard.
- Stroke weight: thin to medium, consistent everywhere. No thick borders.
- Boxes: rectangles with slightly rounded, imperfect corners. Transparent
  fill — the dark background shows through. NO filled boxes, NO shadows,
  NO 3D, NO glow, NO neon.
- Text: hand-lettered look, all lowercase for package names exactly as
  written below, clearly legible, monospace-ish. Do not restyle or
  capitalise any name.
- Arrows: straight or gently curved lines with a simple open arrowhead
  (a plain V, not a filled triangle).
- Colour: STRICTLY two colours only — dark background, white strokes. No
  accent colour anywhere. No red, blue, green, yellow, orange, purple.
- Layout: clean, generous whitespace, well balanced, nothing overlapping,
  no text touching or crossing any line. Every label fully inside the
  image bounds.
- Aspect ratio: landscape, roughly 16:10.
- No title bar, no watermark, no logo, no legend key, no decorative
  flourishes, no icons, no emoji.

CONTENT — draw exactly this, nothing more and nothing less.

the project. Each big box is a Go PACKAGE, with its .go files listed inside.
An arrow means "this package imports that package".

BOX SHAPE — important:
Each package box is a rectangle with the package name at the TOP in slightly

  |---------------------------|   <- thin divider line
